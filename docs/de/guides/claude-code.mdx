GoModel kann Claude Code vorgeschaltet werden, sodass jeder Request zuerst Ihr
eigenes Gateway durchläuft.

Ablauf:

`Claude Code -> GoModel -> Anthropic`

## Bevor Sie beginnen

- Installieren Sie Claude Code auf Ihrem Rechner.
- Wählen Sie einen GoModel-Master-Key, zum Beispiel `change-me`.
- Stellen Sie sicher, dass GoModel Zugangsdaten für den Anthropic-Upstream hat.

<Note>
  Claude Code lässt sich über GoModel routen, unabhängig davon, ob Sie persönlich
  ein Claude-Code-Abonnement nutzen. Im Gateway-Modus kommuniziert Claude Code über
  `ANTHROPIC_BASE_URL` und `ANTHROPIC_AUTH_TOKEN` mit GoModel. GoModel benötigt
  trotzdem einen eigenen `ANTHROPIC_API_KEY`, um Anthropic upstream zu erreichen —
  entweder einen Console-API-Key oder ein OAuth-Token eines Claude-Abonnements.
</Note>

## So erhalten Sie `ANTHROPIC_API_KEY`

**Option A — Console-API-Key (nutzungsbasiert):**

1. Öffnen Sie die Claude Console und melden Sie sich bei Ihrem API-Konto an.
2. Gehen Sie in der Console zu den Kontoeinstellungen und erstellen Sie einen
   API-Key.
3. Kopieren Sie den Key (er wird nur einmal angezeigt) und setzen Sie ihn für
   GoModel als `ANTHROPIC_API_KEY`.

Laut der API-Dokumentation von Anthropic werden API-Keys in den Kontoeinstellungen
der Console erstellt.

<Warning>
  Kostenpflichtige Claude-Pläne (Pro, Max, Team, Enterprise) und die Abrechnung über
  die Claude API Console sind getrennt. Die Nutzung über API-Keys wird als
  API-Nutzung abgerechnet.
</Warning>

**Option B — Token eines Claude-Abonnements (Pro, Max, Team oder Enterprise):**

1. Führen Sie `claude setup-token` auf einem Rechner aus, auf dem Claude Code mit
   Ihrem Abonnement angemeldet ist.
2. Kopieren Sie das erzeugte Token `sk-ant-oat01-...` und setzen Sie es für GoModel
   als `ANTHROPIC_API_KEY`.

GoModel erkennt das Präfix `sk-ant-oat` und authentifiziert sich upstream
automatisch mit dem OAuth-Bearer-Schema. Die Nutzung wird über die Limits Ihres
Abonnements abgedeckt statt über die API-Abrechnung.

<Warning>
  Anthropic autorisiert Abonnement-Tokens **ausschließlich für Traffic von Claude
  Code**. Dieses Setup funktioniert, weil Claude Code der Client bleibt und GoModel
  seine Requests unverändert weiterleitet; andere Clients oder Tools auf dieselben
  Gateway-Zugangsdaten zu richten, wird upstream abgelehnt und verstößt gegen die
  Nutzungsbedingungen von Anthropic.
</Warning>

## 1. GoModel starten

Starten Sie GoModel mit einem Master-Key und einem Anthropic-Provider-Key:

```bash
docker run --rm -p 8080:8080 \
  -e GOMODEL_MASTER_KEY="change-me" \
  -e ANTHROPIC_API_KEY="sk-ant-..." \
  enterpilot/gomodel
```

## 2. Anthropic-Passthrough prüfen

Prüfen Sie, ob der Models-Endpunkt des Anthropic-Passthrough antwortet:

<CodeGroup>

```bash curl
curl -s http://localhost:8080/p/anthropic/v1/models \
  -H "Authorization: Bearer change-me"
```

```python Python
import anthropic

client = anthropic.Anthropic(
    base_url="http://localhost:8080/p/anthropic",
    api_key="change-me",
)

for model in client.models.list():
    print(model.id)
```

```javascript JavaScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "http://localhost:8080/p/anthropic",
  apiKey: "change-me",
});

for await (const model of client.models.list()) {
  console.log(model.id);
}
```

</CodeGroup>

Senden Sie anschließend eine kleine Testnachricht:

<CodeGroup>

```bash curl
curl -s http://localhost:8080/p/anthropic/v1/messages \
  -H "Authorization: Bearer change-me" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-3-haiku-20240307",
    "max_tokens": 16,
    "messages": [
      {
        "role": "user",
        "content": "Reply with exactly ok"
      }
    ]
  }'
```

```python Python
import anthropic

client = anthropic.Anthropic(
    base_url="http://localhost:8080/p/anthropic",
    api_key="change-me",
)

message = client.messages.create(
    model="claude-3-haiku-20240307",
    max_tokens=16,
    messages=[{"role": "user", "content": "Reply with exactly ok"}],
)

print(message.content[0].text)
```

```javascript JavaScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "http://localhost:8080/p/anthropic",
  apiKey: "change-me",
});

const message = await client.messages.create({
  model: "claude-3-haiku-20240307",
  max_tokens: 16,
  messages: [{ role: "user", content: "Reply with exactly ok" }],
});

console.log(message.content[0].text);
```

</CodeGroup>

Ist das Gateway korrekt eingerichtet, enthält die Response `ok`.

## 3. Claude Code für GoModel konfigurieren

Richten Sie Claude Code auf GoModel aus:

```bash
export ANTHROPIC_BASE_URL=http://localhost:8080
export ANTHROPIC_AUTH_TOKEN=change-me
export CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1
```

Die verwaltete Basis-URL stellt `/v1/messages` mit
[nativer Weiterleitung](/de/advanced/anthropic-messages-api#native-weiterleitung-an-anthropic)
bereit: Requests, die zu Anthropic aufgelöst werden, werden abgesehen von der
Auflösung von Modell-Aliasen unverändert weitergeleitet (`cache_control`,
Thinking-Signaturen und Beta-Header bleiben erhalten), während Rate-Limits, Budgets,
Audit und Nutzungserfassung greifen — und Modell-Aliase oder virtuelle Modelle
können Claude Code zu anderen Providern routen. Alternativ verwendet
`ANTHROPIC_BASE_URL=http://localhost:8080/p/anthropic` den reinen Passthrough, der
fest an den Anthropic-Upstream gebunden ist.

Kurzfassung der Claude-Code-Dokumentation: Setzen Sie im Gateway-Modus
`ANTHROPIC_BASE_URL` auf Ihre Gateway-URL und `ANTHROPIC_AUTH_TOKEN` auf Ihr
Gateway-Token und führen Sie Claude Code dann wie gewohnt aus. Siehe die offizielle
Anleitung:
[Claude Code LLM gateway docs](https://code.claude.com/docs/en/llm-gateway).

Läuft GoModel nicht auf Ihrem lokalen Rechner, ersetzen Sie `localhost:8080` durch
den korrekten Host und Port.

## 4. Einen Test-Prompt mit Claude Code ausführen

```bash
claude -p --output-format text --model claude-3-haiku-20240307 \
  'Reply with exactly ok and no punctuation.'
```

Das validierte Ergebnis war:

```text
ok
```

## 5. Den Traffic in GoModel prüfen

Öffnen Sie die Audit-Logs im GoModel-Dashboard:

[http://localhost:8080/admin/dashboard/audit](http://localhost:8080/admin/dashboard/audit)

Hier können Sie am einfachsten bestätigen, dass Claude Code GoModel erreicht, und
den vollständigen Verlauf von Requests und Responses einsehen. Im selben Dashboard
können Sie Ihren GoModel-Traffic und die Nutzung weiter verfolgen.
