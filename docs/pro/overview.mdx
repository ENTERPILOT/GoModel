## What Pro is

GoModel Pro is the commercial distribution of GoModel. It uses the same
gateway, configuration, providers, dashboard, and APIs as open-source
GoModel, with licensed extensions for prompt compression, intelligent routing,
OIDC single sign-on, egress proxy pools, per-child quota templates, and
secret manager vaults.

Without a valid license, the Pro binary starts as the open-source gateway and
does not block traffic. Explicitly enabled SSO, egress pools, per-child quota
templates, and vaults are the exception: startup fails closed when their
entitlement or configuration is invalid, so an authentication boundary cannot
disappear silently, proxied traffic never leaves from the gateway's own
address, limits are not quietly shared, and secrets are never left unresolved.

## Quota templates

Per-child quota templates let one `user_path` budget definition apply
independently to each direct child path instead of one shared subtree budget.
Set `per_child: true` on a `budgets.user_paths` entry — see
[Budgets](/features/budgets#dynamic-per-child-budgets) for YAML and
environment-variable examples and matching rules. Without the
`quota_templates` entitlement, `per_child: true` in configuration aborts
startup and admin API writes are rejected with 403
`quota_templates_not_entitled`.

## Vaults

Vaults add a `vault` scheme to [secret references](/advanced/secret-references),
so provider keys and other secrets are read from HashiCorp Vault, AWS Secrets
Manager, GCP Secret Manager, or Azure Key Vault instead of plain environment
variables:

```yaml
extensions:
  vaults:
    enabled: true
    stores:
      prod:
        type: hashicorp
        address: https://vault.internal:8200
        auth:
          method: kubernetes
          role: gomodel

providers:
  openai:
    api_key: ${vault:prod/llm#openai}
```

Secrets are cached and re-read every `refresh_interval` (default `5m`).
Enabling vaults without the `vaults` entitlement stops startup.

## Licensing

Pro features are granted by an offline Ed25519-signed token in
`GOMODEL_PRO_LICENSE`. Validation requires no network access and works in
air-gapped environments.
