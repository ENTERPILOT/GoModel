<Warning>
  Speechmatics 支持目前处于 Beta 阶段。它已通过针对模拟 API 的自动化测试（该模拟 API 依据
  Speechmatics 公开的 API 参考构建），但尚未在真实的 Speechmatics 服务上验证。如遇问题，请反馈给我们。
</Warning>

Speechmatics 是一个语音转文本提供商。GoModel 通过标准的 `/v1/audio/transcriptions` 端点提供它的
[Batch API](https://docs.speechmatics.com/speech-to-text/batch/quickstart)。Speechmatics 没有聊天、`/responses`
或嵌入 API，GoModel 也不提供它处于预览阶段的文本转语音，因此对于路由到 Speechmatics 的模型，这些端点会返回
`invalid_request_error`。

## 配置

在 [Speechmatics 门户](https://portal.speechmatics.com/settings/api-keys)中创建 API 密钥并设置：

```bash
SPEECHMATICS_API_KEY=...
```

或者在 `config.yaml` 中：

```yaml
providers:
  speechmatics:
    type: speechmatics
    api_key: "${SPEECHMATICS_API_KEY}"
    # base_url 默认为 "https://eu1.asr.api.speechmatics.com/v2"。
```

### 区域

音频在端点所属的区域处理。默认是 EU1；设置 `SPEECHMATICS_BASE_URL` 可使用其他区域：

| 区域 | 基础 URL |
| ---- | -------- |
| EU1（默认） | `https://eu1.asr.api.speechmatics.com/v2` |
| US1 | `https://us1.asr.api.speechmatics.com/v2` |
| AU1 | `https://au1.asr.api.speechmatics.com/v2` |

任务只存在于创建它的区域，因此一个提供商只对应一个区域。要使用两个区域，请配置两个提供商，例如
`speechmatics` 和 `speechmatics-us`，并为它们设置不同的 `base_url`。

## 模型

Speechmatics 没有模型列表接口，因此由 GoModel 自行列出它的批量模型：

| 模型 | 适用场景 |
| ---- | -------- |
| `enhanced` | 最高准确度，每个文件一种语言 |
| `standard` | 处理更快，每个文件一种语言 |
| `melia-1` | 说话人在多种语言之间切换的音频 |
| `oak-1` | 多语言的医疗音频 |

Speechmatics 的模型不在 GoModel 用来定价的模型目录中。用量按音频秒数记录；如需得到成本，请通过[定价覆盖](/zh/features/cost-tracking)为模型设置
`per_second_input` 价格，或在 `config.yaml` 的 `providers.speechmatics.models` 下声明。默认情况下，在 `config.yaml`
中列出了模型的提供商只提供这些模型，因此请列出您使用的每个模型。

## 转录

```bash
curl https://your-gateway/v1/audio/transcriptions \
  -H "Authorization: Bearer $GOMODEL_KEY" \
  -F "file=@meeting.mp3" \
  -F "model=speechmatics/enhanced" \
  -F "language=en"
```

Speechmatics 以异步方式转录。GoModel 将音频作为任务上传，等待任务完成，并在同一个响应中返回转录结果，因此客户端看到的是一次普通的同步调用。

- GoModel 最多等待 10 分钟。超时后返回 `504` 并终止任务。
- 客户端断开连接时，任务同样会被终止，避免为无人读取的结果继续运行。
- 已完成的任务会在 Speechmatics 自身的保留期（7 天）内保留在您的 Speechmatics 账户中；GoModel 不会删除它。
- 配置了多个 API 密钥时，同一个任务的所有调用使用同一个密钥。

### 参数

| OpenAI 参数 | Speechmatics |
| ----------- | ------------ |
| `model` | 任务的 `model` |
| `language` | 任务的 `language`。`zh` 会作为 `cmn` 发送；`cmn_en` 等 Speechmatics 语言包会原样传递。 |
| `response_format` | `json`（默认）、`text`、`verbose_json`、`srt`、`vtt` |
| `timestamp_granularities[]` | `word` 会在 `verbose_json` 中加入 `words` |
| `prompt`、`temperature` | 被忽略：Speechmatics 没有对应的参数 |

其他表单字段不会被转发，因为 Speechmatics 的任务使用 JSON 而不是表单字段进行配置。说话人分离、自定义词典等其他任务选项请使用[透传](#原生透传)。

**不提供 `language` 时**，`enhanced` 和 `standard` 会识别语言（`"language": "auto"`），并使用最匹配的语言转录。语言识别需要足够的语音：Speechmatics
建议至少 60 秒，并会拒绝找不到语音的文件。已知语言时请发送 `language`。

**`melia-1` 和 `oak-1`** 会自行检测语言。GoModel 始终向它们发送 `"language": "multi"`，并将您的 `language` 作为语言提示传递。

### 响应格式

- `json`：转录文本，以及与 `whisper-1` 相同的 `usage` 音频时长
  （`{"type": "duration", "seconds": 4}`）。
- `text`：转录文本。
- `verbose_json`：增加 `language`（Speechmatics 报告的代码，例如 `en`）、`duration`（整秒）和
  `segments`：每句话一个，各包含 `id`、`start`、`end` 和 `text`。不包含 Whisper 的解码器统计信息（`tokens`、`avg_logprob`
  等）。请求 `word` 粒度可同时获得带逐词时间的 `words`。
- `srt`：Speechmatics 自己的 SubRip 输出。
- `vtt`：同样的字幕，转换为 WebVTT。

### 错误

- 被 Speechmatics 拒绝的任务（音频无法读取、无法识别语言、不支持的语言）返回 `400`，并附带 Speechmatics 给出的原因。
- 未能按时完成的任务返回 `504`。
- 其他 Speechmatics 错误保留其状态码和消息。

## 原生透传

将 `speechmatics` 添加到 `ENABLED_PASSTHROUGH_PROVIDERS`，即可通过[透传](/zh/features/passthrough-api)直接调用 Batch API，例如
`POST /p/speechmatics/jobs` 和 `GET /p/speechmatics/jobs/{id}/transcript`。GoModel 会加上 Speechmatics 凭据，并原样转发请求。

## 未实现

- **实时转录**：Speechmatics 的实时 WebSocket API 使用自己的消息协议，而不是 `/v1/realtime` 所中继的 OpenAI Realtime 协议。
- **文本转语音**：在 Speechmatics 处于预览阶段，且位于单独的端点。
- **翻译**（`/v1/audio/translations`）、说话人分离、自定义词典以及语音智能功能的类型化参数。
