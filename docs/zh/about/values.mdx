## 1. 质量

我们的目标是超越 LiteLLM，而质量正是实现这一目标的途径。

AI 网关不一定要用 Python 编写。我们选择 Go，是因为运行时行为、部署形态和长期可维护性都至关重要。

罐子是一个很好的提醒：如果先装满沙子，之后大石头就放不进去了。在 GoModel 中，大石头是经验、编程语言和架构；
沙子是较小的工作：功能、函数、测试和修复。

大石头优先。

<Note>
  我们依然尊重 LiteLLM 及其背后的团队。他们是先行者，帮助了大量开发者快速交付产品，也证明了这一领域的价值。
</Note>

## 2. 效率

这既适用于运行时，也适用于我们的工作方式。我们使用能帮助我们更快推进、同时保持高质量的工具，包括 Claude Code、Codex、CodeRabbit 和 GitHub Copilot。

## 3. 透明

GoModel 是开源的，我们希望让它可持续发展。这意味着我们最终可能会向大型企业收费，以便项目能够持续发布新版本。
