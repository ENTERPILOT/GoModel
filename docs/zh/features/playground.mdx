**Playground**（调试台）页面（`/admin/dashboard/playground`）使用您的控制台密钥，通过网关的公开 API 发送请求，
因此每次调用都会像客户端请求一样被路由、记录日志和计量。您可以选择端点（`/v1/chat/completions`、
`/v1/responses` 或 `/v1/messages`）、库存中的模型或任意别名、按名称指定的虚拟模型，以及是否使用流式传输；
通过可编辑、可重新排序的 System、User 和 Assistant 消息构建对话；然后发送提示词。
右侧的 JSON 面板会显示即将发送的请求体（随编辑实时更新），以及最近一次响应及其状态、延迟和 Token 用量——
流式响应会被组装成与非流式调用返回结果相同的结构。
这些请求与网关的任何其他客户端一样，受相同的预算、速率限制、护栏和审计日志约束。

## 图片、语音与转录

模型选择器上方的 **模式** 开关也可以用来测试媒体模型。每种模式都会调用网关兼容 OpenAI 的端点，
并优先列出元数据中声明支持该模式的模型；您仍然可以输入任意模型或别名。

| 模式 | 端点 | 输入 | 结果 |
| --- | --- | --- | --- |
| 聊天 | 在 **端点** 中选择的端点 | 对话 | 助手消息 |
| 图像 | `POST /v1/images/generations` | 提示词、尺寸、图片数量（1–4） | 生成的图片（URL 或 `b64_json`） |
| 语音合成 | `POST /v1/audio/speech` | 文本、音色、格式（`mp3`、`wav`、`opus`、`aac`、`flac`） | 音频播放器 |
| 转录 | `POST /v1/audio/transcriptions` | 音频文件，可选的语言和提示词 | 转录文本 |

只有当尺寸、数量和格式与提供商默认值不同时才会发送这些参数（语音的默认格式为 `mp3`）。JSON 面板会显示请求体；
转录请求以 `multipart/form-data` 发送，因此其预览描述的是文件部分，而不包含文件字节。为保持可读性，
响应 JSON 中的内联 `b64_json` 图片会被缩短，语音响应则会汇总显示为其内容类型和大小。

## 用户路径作用域

虚拟模型可以被限定到特定的 `user_paths`，而使用主密钥认证的 Playground 请求可以通过模型选择器旁边的 **User path**
字段，将自身限定到其中一个路径。当您选择的模型的策略声明了 `user_paths` 时，该字段会预填第一个条目；您可以在发送前对其进行编辑。
发送时，该值会通过用户路径请求头传递，与外部客户端的发送方式完全相同，因此网关会在请求快照中记录该路径，并授予对限定到该路径的模型的访问权限——
不带该请求头的请求将被拒绝访问这些模型。

请求头名称默认为 `X-GoModel-User-Path`。如果您通过 `USER_PATH_HEADER`（或 `server.user_path_header`）自定义了它，
控制台会从 `GET /admin/runtime/config` 读取实际生效的名称，并在该请求头下发送限定的路径，因此无需在控制台中进行额外配置。
