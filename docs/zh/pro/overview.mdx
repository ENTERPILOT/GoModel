## Pro 是什么

GoModel Pro 是 GoModel 的商业发行版。它与开源版 GoModel 使用相同的网关、配置、提供商、控制台和 API，并提供需授权的扩展功能：
提示词压缩、智能路由、OIDC 单点登录、出站代理池、按子路径的配额模板以及密钥管理器 Vaults。

没有有效许可证时，Pro 二进制文件会以开源网关的形式启动，且不会阻断流量。显式启用的 SSO、出站代理池、按子路径的配额模板和 Vaults 是例外：
当其授权或配置无效时，启动会失败即拒绝（fail closed），这样认证边界就不会悄无声息地消失，经代理的流量永远不会从网关自身的地址发出，
限额不会被悄悄共享，密钥也不会处于未解析状态。

## 配额模板

按子路径的配额模板可以让一个 `user_path` 预算定义独立地应用于每个直接子路径，而不是整个子树共享一个预算。
请在 `budgets.user_paths` 条目上设置 `per_child: true`——YAML 和环境变量示例以及匹配规则请参阅
[预算](/zh/features/budgets#动态的子路径预算)。没有 `quota_templates` 授权时，配置中的 `per_child: true` 会导致启动中止，
Admin API 写入会被拒绝并返回 403 `quota_templates_not_entitled`。

## Vaults

Vaults 为[密钥引用](/zh/advanced/secret-references)增加了 `vault` 方案，使提供商密钥和其他机密可以从 HashiCorp Vault、
AWS Secrets Manager、GCP Secret Manager 或 Azure Key Vault 读取，而不是来自普通环境变量：

```yaml
extensions:
  vaults:
    enabled: true
    stores:
      prod:
        type: hashicorp
        address: https://vault.internal:8200
        auth:
          method: kubernetes
          role: gomodel

providers:
  openai:
    api_key: ${vault:prod/llm#openai}
```

机密会被缓存，并每隔 `refresh_interval`（默认 `5m`）重新读取。在没有 `vaults` 授权的情况下启用 Vaults 会导致启动中止。

## 许可证

Pro 功能通过 `GOMODEL_PRO_LICENSE` 中的离线 Ed25519 签名令牌授予。校验无需网络访问，可在离线隔离环境中正常工作。
